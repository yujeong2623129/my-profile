# My Profile — 자기소개 웹페이지

HTML과 CSS를 학습하며 제작한 첫 번째 개인 웹 프로젝트입니다.

## 프로젝트 소개

자기소개, 프로젝트 경험, 공부 중인 프로그래밍 언어와 GitHub 링크를 보여주는 정적 웹페이지입니다.

## 사용 기술

- HTML5 — 웹페이지 구조 및 콘텐츠
- CSS3 — 색상, 글꼴, 레이아웃 디자인

## 주요 기능

- 이름 및 자기소개 표시
- 프로젝트에서 맡은 역할 소개
- 학습 중인 기술을 배지 형태로 표시
- GitHub 프로필로 이동하는 링크
  
## 프로젝트 구조

```text
my-profile/
├── index.html
├── style.css
└── README.md
```
